# Purpose and principles

**Status:** Current  
**Last updated:** 29 September 2026

## Purpose

Gitaverse is a verse-centred Gita application for reading, listening, chanting, and gradually building a personal relationship with the Bhagavad Gita. It is a distinct distribution within the wider Gitajyoti ecosystem: Gitaverse concentrates on verses and chanting, while MyGita concentrates on deeper understanding and life application.

## Product principles

- **The verse is central.** Navigation, language, audio, and future media support the shloka rather than compete with it.
- **Calm before novelty.** The interface should feel serene, text-friendly, and usable for sustained reading.
- **One person, one local journey.** Profiles separate preferences and progress on a shared device without requiring authentication.
- **Stable identity.** Every canonical record uses SID, such as `6.B`, `6.7`, or `6.E`.
- **Language is a perspective on shared content.** Sanskrit, English, and Kannada records align by SID.
- **Experiences compose collections.** Verse text and reusable media are independent of the experience that presents them.
- **Progressive capability.** The same application should work online, as an installed PWA, and—with an explicit folder choice—for local editing.
- **Privacy by design.** Profile details remain local. Analytics uses grouped, non-PII context.
