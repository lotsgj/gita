# Home and experience selection

**Status:** Current  
**Last updated:** 29 September 2026

## Home

After a profile is active, Home presents the available learning experiences. The profile pill stays visible at the upper right. About Gitaverse and installation are available from landing surfaces.

## Choices

Gita 700 is selectable and opens the shared player with its renderer. Gita Yoga and Gita Sara are visible as coming-later choices so the intended experience family is understandable without implying they are implemented.

Choosing an experience preserves the profile identifier and preferred content language in application navigation. The profile’s app language governs this interface; `lang` links affect content only. The Home command (`A`) returns from the player to this experience-selection view and records Home as the resumable location.

## About

About Gitaverse is available throughout the path from profile setup to the player. It uses the flute as a Krishna-associated visual symbol, links to Gitajyoti and Light of the Self, and displays the deployed application version.
